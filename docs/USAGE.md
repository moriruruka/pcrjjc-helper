# 使用

## 指令一览（AstrBot 插件）

| 指令 | 说明 | 谁能用 |
| --- | --- | --- |
| `作业 布丁 克总` / `/作业 布丁 克总` | 按角色名查作业，最多 5 个角色 | 群里任何人 |
| 直接发截图 | 自动识图（需 `image_auto=true`） | 同上 |
| `作业` + 截图 | 强制走识图 | 同上 |
| `作业`（不带参数） | 用**最近一次**识别的阵容再查一遍 | 同上 |
| `pcr 角色 克总` | 查角色 id / 中文名 / 别称 | 同上 |
| `pcr 状态` | 看角色数、头像数、更新时间、追问配置 | 同上 |
| `pcr 更新` | 立刻刷新角色表与头像（默认 7 天自动一次） | 同上 |
| `pcr 帮助` | 指令速查 | 同上 |
| 追问中回 `1` / `2` | 1 = 排除一个角色再查，2 = 替换一个角色再查 | 发起者本人 |

> 关键词触发：面板里 `keywords` 默认是 `["作业"]`，所以群里说「作业 布丁」也能触发，不用带斜杠。

## 查不到作业时会发生什么

```
你：作业 布丁 克总 真琴 纺希 莉莎
机器人：（卡片）
     ↘ 如果一支队伍都没查到：
       这个防守暂时没查到作业。
       ① 回 1：排除一个角色再查
       ② 回 2：把某个角色换掉再查
       （2 分钟内没回，这件事就先放下）
```

### 排除法（回 1）

```
你：1
机器人：要排除哪个角色？① 莉莎 ② 纺希 ③ 真琴 ④ 克总 ⑤ 布丁
你：3 号位            ← 也可以直接说「真琴」，或再发一张图圈出它
机器人：（4 人阵容的卡片）
```

- 位置编号从**右边数**：最右边是前卫（1 号位），最左边是后卫（5 号位）。
- 一直排除到只剩 2 个角色时，机器人会先提醒「人越少越不准，仅供参考」，再出卡片。

### 替换法（回 2）

```
你：2
机器人：把谁换成谁？例如「3 号位换成克总」或「布丁换成宫子」
你：3 号位换成克总
机器人：好，把 3 号位的「真琴」换成「克莉丝提娜」，再查一次……
```

- 只能打字（头像图没法表达“换成谁”）。
- 换上去的角色**已经在这队里**时会提示重复并要求重说，不会瞎换。
- 替换后仍查不到，会回到「回 1 / 回 2」继续问，最多 `dialog_max_rounds` 轮。

### 主动触发

已经查到作业、但你对结果不满意时，可以直接说：

- `竞技场阵容排除` → 直接用上一次查的阵容进入排除流程
- `竞技场阵容替换` → 同上，进入替换流程

前提是**上一次对话确实在查作业**（有效期内，默认 10 分钟），否则不响应，避免误触。

### 退出

回「算了」「取消」「不查了」「停」任意一个，追问立即结束。超时（默认选 1/2 等 2 分钟、细节等 2 分钟）也会自动结束并提示一句。

## 配置项（面板 / `config.json`）

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `region` | `1` | 1 国服 / 2 国际服 / 3 日服；0 = 全部（接口按 1 发） |
| `max_results` | `5` | 每次出卡片最多几支队伍 |
| `sort_mode` | `ratio` | `ratio` 赞踩比 / `time` 最新 / `likes` 赞数 |
| `show_names` | `slang` | `slang` 黑话 / `official` 官译 / `none` 不显示 |
| `use_ai_names` | `true` | 用整理过的中文名（否则用网站原名） |
| `show_likes` | `true` | 卡片显示赞/踩 |
| `show_time` | `true` | 卡片显示作业时间 |
| `keywords` | `["作业"]` | 群聊关键词触发；留空则只认指令 |
| `text_mode` | `false` | 开 = 只回文字表格，不出图 |
| `card_max_items` | `8` | 一张卡片最多几支队伍 |
| `enable_image` | `true` | 总开关：关掉后完全不走截图识别 |
| `image_auto` | `true` | 收到图就自动识图（否则要带 `作业` 前缀） |
| `image_threshold` | `0.7` | 识别阈值（0.6 更宽松，0.8 更严格） |
| `icon_source` | estertion CDN | 头像来源，可改成你自己的镜像 |
| `auto_update_days` | `7` | 多少天自动刷新一次角色表与头像，0 = 关闭 |
| `request_timeout` | `15` | 请求超时（秒） |
| `allow_group` | `true` | 是否响应群消息 |
| `dialog_timeout_min` | `2` | 等用户回 1/2 的分钟数（0 = 关闭追问） |
| `dialog_step_timeout_min` | `2` | 追问细节（排除谁 / 换成谁）的分钟数 |
| `dialog_max_rounds` | `6` | 最多追问多少轮 |
| `dialog_active_minutes` | `10` | 主动触发词的有效期（分钟），0 = 关闭 |
| `auth_key` | 空 | 作业网 API key（可选；没有就走匿名接口） |
| `use_clip` | `false` | 实验项：用 CLIP 辅助识别（需另装 torch） |
| `browser_endpoint` | 空 | 可选：本机浏览器转发服务地址（见下） |

## 命令行

```bash
pcrjjc arena -n 布丁,克总,真琴           # 查作业（文字）
pcrjjc arena -n 布丁,克总 --json         # 输出原始 JSON
pcrjjc arena --ids 100701,107101        # 直接给 id
pcrjjc recognize -i shot.png            # 从截图识别阵容
pcrjjc recognize -i shot.png --json
pcrjjc avatars                          # 下载全部头像
pcrjjc avatars --only 布丁,克总         # 只下这几个
pcrjjc refresh                          # 刷新角色表
pcrjjc selftest                         # 离线自检
pcrjjc doctor                           # 看依赖 / 字体 / 数据
```

环境变量：

| 变量 | 作用 |
| --- | --- |
| `PCRJJC_DATA_DIR` | 数据目录（角色表、头像、缓存） |
| `PCRJJC_FONT` | 指定中文字体文件 |
| `PCRJJC_REGION` | 默认区服 |
| `PCRJJC_TIMEOUT` | 默认请求超时 |
| `PCRJJC_ICON_SOURCE` | 头像来源 |
| `PCRJJC_AUTH_KEY` | 作业网 API key（有就用直连接口） |
| `PCRJJC_BROWSER_ENDPOINT` | 本机浏览器转发服务地址 |

## 查询慢怎么办（三档方案）

实测：配置了本机浏览器服务时，一条查询 **3 秒**出卡片；首次识别截图会额外多花 1–2 分钟建头像特征缓存，之后就快了。

1. **有作业网 API key** → 面板填 `auth_key`，走直连接口，通常 1–3 秒。
2. **起本机浏览器服务**（推荐，无需 key）：
   ```bash
   pip install playwright
   python -m playwright install msedge        # 或用系统自带 Edge
   python scripts/browser_bridge.py --login   # 首次：弹一次窗口登录作业网，登录完自动关
   python scripts/browser_bridge.py           # 之后：headless 常驻，窗口不可见
   ```
   然后把面板里的 `browser_endpoint` 填成 `http://127.0.0.1:6191`。
   它做的事是「用真实浏览器打开作业网自己的页面，把页面发出的查询响应截下来」，签名与 Cookie 都由浏览器处理，所以不会被当成脚本。
3. **什么都不配**：`browser_endpoint` 留空、`auth_key` 留空 → 只走匿名接口，失败就提示「稍后再查」。最稳但最慢（每次要等接口超时）。

要点：
- 浏览器服务**默认 headless**，不会弹空白窗口；只有 `--login` 那一次会开窗口，登录完成后自动关闭。
- 首次截图识别会建缓存（`avatar_prints.json`），773 张头像约 1–2 分钟，只付一次。

## 关于作业网风控

pcrdfans 的匿名接口有时会返回 `103 / 601`（未登录或触发风控）。两条路：

1. **等一等再查**（最常见）。插件对 429/Cloudflare 会给出明确提示。
2. **自备浏览器转发服务**：在本机跑一个「用真实浏览器打开作业网、把页面发出的请求截下来」的小服务，监听 `127.0.0.1`，然后把 `browser_endpoint` 指向它（例如 `http://127.0.0.1:6191`）。这属于进阶用法，需要自己装 Playwright；仓库不提供账号与 Cookie。

## 追问状态在哪

追问状态只存在内存里，机器人重启即失效（已经发出去的卡片不受影响）。单会话同时只有一条追问，多条会覆盖旧的。
