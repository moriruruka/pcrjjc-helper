# 公主连结竞技场作业自助查询（pcrjjc）

在群里发一句话或一张截图，机器人去 pcrdfans 查作业，回一张作业卡片。

## 两条使用入口

| 入口 | 怎么用 |
| --- | --- |
| 指令 | `作业 布丁 克总` / `/作业 布丁 克总`（最多 5 个角色） |
| 截图 | `/作业` + 一张竞技场截图（5 个头像并排），或消息里带关键词「作业」+ 截图 |

表情包、动图与缩略图不会被当作竞技场截图：识别前会依据尺寸、帧数与长宽比过滤，带关键词的图片消息同样适用。

支持角色原名、日文名、英文名、B 服译名与黑话别称，并允许一个字的错写（如 `宫紫`）。

## 查不到作业时

会先问你要怎么办：

```
回 1：排除一个角色，用剩下的再查
回 2：把一个角色换成另一个，再查
回「取消」：停
```

- 「排除」可以说名字（`布丁`）、说位置（`3号位`），也可以再发一张头像截图。
- 位置编号**从右往左数**：最右边是前卫（1 号位），最左边是后卫（5 号位）。
- 「替换」只能打字，例如 `3号位换成克总`；换上去的人如果已经在队里，会提示重复并要求重说。
- 一直排除到只剩 2 个角色时会先提醒「人越少越不准」，再出卡片。
- 已查到作业但需要其它方案时，可发送 `竞技场阵容排除` 或 `竞技场阵容替换`（10 分钟内有效，且要求上一次对话确为作业查询）。

## 配置

所有开关都在 AstrBot 面板的插件配置里，常用的几个：

| 项 | 默认 | 说明 |
| --- | --- | --- |
| `region` | 1 | 1 国服 / 2 国际服 / 3 日服；0 = 全部（接口按 1 发） |
| `max_results` | 5 | 一次出几支队伍 |
| `sort_mode` | ratio | `ratio` 赞踩比 / `time` 最新 / `likes` 赞数 |
| `show_names` | slang | `slang` 黑话 / `official` 官译 / `none` 不显示 |
| `keywords` | `["作业"]` | 群聊里不带 `/` 也能触发的关键词 |
| `image_auto` | 开 | 是否允许「关键词 + 截图」自动识图 |
| `image_threshold` | 0.7 | 识别阈值，0.6 更宽松，0.8 更严格 |
| `browser_endpoint` | 空 | 填了就走本机浏览器查询（见下） |
| `auth_key` | 空 | 有作业网 API key 就填，最快 |

## 查询慢怎么办

作业网的匿名接口经常超时（15 秒），兜底还要再等一次浏览器，单次 70–90 秒。三档方案，从快到慢：

1. **配置 `auth_key`**：直接调用接口，通常 1–3 秒。
2. **起本机浏览器服务**（仓库里的 `scripts/browser_bridge.py`，或你自己的等价服务），把 `browser_endpoint` 填成它的地址（例如 `http://127.0.0.1:6191`）。之后查询 3–8 秒，浏览器窗口默认不可见。
3. **均不配置**：`browser_endpoint` 留空时仅使用匿名接口，失败时提示稍后重试，稳定性最高但延迟最大。

## 数据与头像

- 角色表 353 个随插件发布，不用联网。
- 头像（约 15 MB、770 多张）不随包：首次可以 `pcr 更新` 自动下载，或用 `pcrjjc avatars`，或从 Release 的 `avatars-v1.zip` 解压到数据目录。
- 没头像也能用，卡片会给占位块，只是不好看。

## 命令

| 指令 | 说明 |
| --- | --- |
| `pcr 状态` | 角色数、头像数、更新时间、追问配置、数据目录 |
| `pcr 角色 克总` | 查 id / 中文名 / 别称 |
| `pcr 更新` | 立刻刷新角色表与头像 |
| `pcr 帮助` | 指令速查 |

## 依赖

`Pillow`、`aiohttp` 必需；`numpy` + `opencv-python-headless` 用于截图识别（约 40 MB）。
未安装时仍可使用文字查询，发送截图会提示安装依赖。识别完全在本地完成，不需要任何模型。
