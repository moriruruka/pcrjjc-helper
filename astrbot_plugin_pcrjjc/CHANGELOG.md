# 更新记录

## v0.1.0 — 2026-11-02

首个版本。

- 文字查作业：角色原名 / 日文名 / 英文名 / B 服译名 / 黑话别称，容错一个字的错写。
- 截图识阵容：从竞技场截图里找出 5 个头像框，用 88×54 脸带做归一化互相关；纯 CPU、本地运行、不需要模型。
- 作业卡片：赞踩比 / 时间 / 赞数排序，三种名字显示模式。
- 查不到时追问：回 1 排除一个角色、回 2 替换一个角色；支持说名字、说位置、发头像截图；有轮数上限与分阶段超时。
- 主动触发：`竞技场阵容排除` / `竞技场阵容替换`，仅在有效期内且上次确实查过作业时响应。
- 数据：353 个角色的角色表随插件发布；头像按需下载（约 15 MB）；每 7 天自动检查更新。
- 可选加速：填 `auth_key` 走直连接口，或填 `browser_endpoint` 走本机浏览器服务。
